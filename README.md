# Mora Studio (`itzmenorah.com`)

A quiet, lightweight personal design and writing portfolio exploring web design, product concepts, interiors, crafts, and short stories through a calm Norwegian minimalist lens.

## Repository Structure

```text
mora-studio/
├── index.html          # Homepage with hero, selected works, and journal previews
├── work.html           # Full portfolio of physical and digital studies
├── journal.html        # Short stories and creative reflections
├── about.html          # Safe studio background and principles
├── style.css           # Minimalist design system and responsive styles
├── script.js           # Lightweight accessibility & mobile navigation scripts
├── CNAME               # Apex custom domain (itzmenorah.com)
├── images/             # Visual assets
│   ├── quiet-room.jpg
│   ├── folded-object.jpg
│   └── little-web-home.jpg
└── README.md
```
